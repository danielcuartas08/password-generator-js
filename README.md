# 🔑 Generador de Contraseñas Seguras

Aplicación web desarrollada para generar contraseñas aleatorias, seguras y personalizables en tiempo real, ayudando a mejorar la seguridad de las cuentas de usuario mediante la combinación de caracteres especiales, mayúsculas, minúsculas y números.

---

### 🛠️ Tecnologías Utilizadas

<p align="left">
  <img src="https://skillicons.dev/icons?i=js,html,css" alt="Tech Stack"/>
</p>

* **HTML5:** Estructura de la interfaz de usuario.
* **CSS3:** Estilos visuales, diseño responsive y estados interactivos.
* **JavaScript (Vanilla JS):** Lógica para generación aleatoria de cadenas, algoritmos de selección y copiado al portapapeles.

---

### ✨ Características Principales

* 🎲 **Generación Aleatoria:** Creación instantánea de contraseñas basadas en conjuntos de caracteres robustos.
* ⚙️ **Parámetros Configurables:** Opción de ajustar longitud y tipos de caracteres (números, símbolos, mayúsculas).
* 📋 **Copiado Rápido:** Copia de contraseña al portapapeles con un solo clic para mayor comodidad.
